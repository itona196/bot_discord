# Bot Discord - Blackjack

Petit bot Discord pour jouer au Blackjack (slash command `/blackjack` + boutons).

## Prérequis
- Node.js 18+  
- Un bot Discord créé sur le Developer Portal (tu auras besoin de `DISCORD_TOKEN` et `CLIENT_ID`)  
- `GUILD_ID` du serveur de test (Developer Mode → Copy ID)
